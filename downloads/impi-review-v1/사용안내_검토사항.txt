임피역 도면 판독 CSV — 검토용 v1
작성일: 2026-10-23

이 자료는 사용자 첨부 도면 이미지 11장에서 보이는 표기와 표고 차를 정리한 검토 초안입니다.
원본 PDF/CAD, 도면 단위, 실측값 및 전문가 대조를 완료한 확정 치수표가 아닙니다.
치수 표기는 실제 mm로 해석했습니다. 입력용 CSV 값은 이미 1:80으로 줄인 값이 아닙니다.
사이트에서 축척 1:80을 선택하면 한 번만 환산됩니다.

1. impi_import_real_mm_REVIEW.csv
현재 웹 도구의 단순 외형 비교에 임시 대응할 4개 값입니다.
width = 17140: 가로 축간 기준거리. 외벽 바깥선이나 처마 끝 길이 확정값이 아닙니다.
depth = 5740: 본체 횡방향 축간 기준거리. 뒤쪽 추가 1900 구간은 포함하지 않았습니다.
wallHeight = 4412: 처마도리 상부의 기준고 ±0 대비 표고를 벽 높이에 임시 대응했습니다.
roofRise = 2170: 낮은 용마루 표고 6582에서 처마도리 표고 4412를 뺀 계산값입니다.
높은 용마루 7532, 추가 박공, 차양, 굴뚝, 뒤쪽 구간은 이 4개 값으로 재현되지 않습니다.
창문 폭·높이와 출입문 폭·높이는 미확정이므로 빈칸입니다. 0이나 추정값으로 채우지 않았습니다.
빈칸은 웹 도구에서 기존값을 지우지 않습니다. 사이트에 남는 값은 이 도면으로 검증된 값이 아닙니다.
제작용 도면이나 절단 파일의 확정 치수로 사용하지 마세요.

웹 도구 사용 순서
- 현재 작업을 유지한 채 자료 수집에서 샘플 '건축물_기초치수.csv'가 있다면 그 샘플만 제거합니다.
  다른 실제 치수 CSV가 있다면 중복·상충 값이 없는지도 확인합니다.
- '자료 추가'로 impi_import_real_mm_REVIEW.csv를 첨부합니다.
- '자료 분석'을 누르면 CSV의 4개 값이 '확정 전' 제안으로 나옵니다. AI API 키는 필요 없습니다.
- 근거표와 원본을 대조한 뒤 '제안 치수 반영'을 누릅니다.
- 설계 기준에서 축척 1:80, 미확정 창문·문 치수, 제작 재료 두께를 확인합니다.
- 원본 대조 확인은 실제 대조를 마친 뒤에 체크하세요.
현재 도구는 직사각형 본체·단일 박공지붕·고정 창문 배치의 예시 생성기입니다.
CSV를 넣는 것만으로 첨부 도면의 임피역 전체 형상이 재현되지는 않습니다.

2. impi_dimensions_evidence_1-80_REVIEW.csv
치수 표기·표고·계산식·판독 후보·미확정 항목과 1:80 환산값을 함께 기록했습니다.
'판독 제안'은 확인 완료가 아닙니다. source_value_mm가 비어 있으면 값을 확정하지 않았다는 뜻입니다.
이 상세 근거표는 현재 사이트의 2열 입력 형식이 아니므로 자동 치수 반영용으로 쓰지 않습니다.
첨부 01의 5739/7639 판독 후보와 다른 도면의 5740/7640은 원본 확대 대조가 필요합니다.
표고 차로 계산한 높이도 실제 재료 외곽선에 대응하는지 별도 검토해야 합니다.

3. impi_source_images.csv
숫자는 사용자 메시지에서 첨부된 이미지 순서 01~11입니다. 원본 파일명이나 도면 번호를 추정하지 않았습니다.
원본 출처: 이 대화에 사용자가 첨부한 이미지 11장.
