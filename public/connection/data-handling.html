현재 공개 작업실

사용자가 올린 원본 파일은 해당 브라우저의 IndexedDB에, 프로젝트 형상·치수·근거·이력은 localStorage에 저장됩니다. 다른 기기와 자동 동기화하지 않습니다. 원본 포함 ZIP은 사용자가 내려받아 보관합니다.

현재 공개 사이트는 생성형 AI 실행부와 연결되지 않았습니다. 로컬 윤곽 추출은 브라우저에서 수행하며 외부 AI로 이미지를 보내지 않습니다.

정적 화면과 파일은 GitHub Pages에서 제공합니다. 호스팅 제공자의 데이터 처리는 해당 제공자의 정책을 따릅니다. 이 설명은 호스팅 제공자의 로그 보관을 통제하거나 보장한다는 의미가 아닙니다.

원격 AI 연결 준비

승인 후 구현할 원격 경로에서는 사용자가 선택한 이미지 표현과 요청 내용을 보호된 실행부와 OpenAI에 보내는 구성을 검토합니다. 원본 전체의 서버 장기 보관은 이번 구성의 기본값으로 계획하지 않습니다. 실제 전송·보관·삭제·로그아웃 동작은 원격 실행부를 구현하고 검증한 뒤 안내합니다.

공급자 인증 토큰과 앱 비밀 값은 보호된 서버에 보관하는 구성이 필요합니다. 이를 정적 웹 코드·브라우저 프로젝트 저장·Git·로그·채팅에 넣지 않습니다. 현재 개인 실행용 인증 코드가 있다는 사실은 원격 보안 구성이 완료됐다는 뜻이 아닙니다.

신청 안내 페이지에는 서비스 소개 초안만 있으며 이름·이메일·계정 정보 입력란이 없습니다. 신청자는 공식 OpenAI 페이지에서 본인 정보를 입력합니다. 이 안내 페이지에서 신청이나 승인을 자동 제출·조회하지 않습니다.

현재 확인 가능한 자료

작업실 · 임피역 검토 사례의 자료 출처 · 기능·검증 범위

별도 API 과금과 새 유료 호스팅은 활성화하지 않았습니다. 연결 승인·사용자 동의·모델 권한·작은 실제 이미지 요청을 각각 확인한 후 서비스 상태를 갱신합니다.
