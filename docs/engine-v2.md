# 가변 이미지 추정 엔진 v2

## 데이터와 지원 형상

`tradiative.building.v2`는 개별 wall/roof/opening/detail/base 요소, 로컬 XY 윤곽, Y-up 배치, XYZ 회전(라디안), 제작 두께를 저장합니다. 개구부는 부모 벽 좌표에 있는 별도 객체입니다. 패널은 단순 다각형, 개구부 프레임은 직사각형을 지원합니다. 평면 패널 데이터로 여러 매스의 수동 형상 표현은 가능하지만, 로컬 추정기가 사진에서 임의의 완전한 건물 구조를 자동 복원하는 것은 아닙니다.

관찰 이미지 좌표는 분석용 리샘플링 래스터의 px, 제작 좌표는 모형 mm입니다. 상대 비례는 크기 설정을 통해 변환합니다. 실제 기준 길이가 없으면 target-width/assumed-real이며 실측 축척으로 표시하지 않습니다. 재료는 실제 구매할 두께로 별도 관리합니다.

각 요소는 observed/inferred/designed 근거와 sourceId·페이지·픽셀 영역·선택 이유·불확실성·대안을 가집니다. 사용자 확인과 실측 확인은 별도 필드입니다. AI 출력은 이 확인 값을 세팅할 수 없습니다. 개별 잠금은 그 부모도 보호해 자식의 월드 위치가 달라지지 않게 합니다. 잠금 상태의 전체 크기·제작 조건 변경은 조용히 적용하지 않습니다.

## 로컬 추정 과정

1. 선택 이미지/PDF 한 페이지를 최대 긴 변 1,000 px의 래스터로 처리합니다. 사용자가 영역을 지정할 수 있습니다.
2. 배경 대비·연결 성분과 CAD 청록 경계를 이용해 건물 후보와 상부 윤곽을 찾습니다. 명확한 윤곽이 없으면 실패하며 기본 집으로 바꾸지 않습니다.
3. 어두운/청록 경계의 개구부 후보를 그룹화해 개별 위치·크기로 만듭니다. 보이는 면에 고정 창문 배열을 넣지 않습니다.
4. 입면 윤곽을 목표 폭에 비례 환산합니다. 깊이는 입력한 비율의 가정이며 후면·측면은 그 가정으로 닫습니다. 선택한 보완 범위에 따라 후면 창호를 별도 designed 요소로 만듭니다.
5. 윤곽 상부 구간을 깊이 방향의 평면 지붕 패널로 연결합니다. 이 방식은 실제 교차 지붕의 공간적 교차선을 알지 못합니다.
6. 수치 검사를 거쳐 벽 밖 개구부의 최소 이동처럼 지원하는 보완만 수행합니다. 잠긴 요소는 바꾸지 않습니다. 해결하지 못한 오류는 남기고 내보내기를 차단합니다.

이는 윤곽·대비 기반 브라우저 추정이며 생성형 AI의 의미 해석·OCR·검색은 아닙니다. 사진의 가림·배경·원근·복잡한 표제란 때문에 결과가 틀릴 수 있습니다. 분석 영역과 정면 자료를 골라 원본과 비교해야 합니다. 원근 사진은 불확실성을 높게 표시하며 정확한 원근 보정 완료로 취급하지 않습니다.

## 비교와 자동 보완

원본 위에 현재 입면·개구부의 투영을 겹쳐 봅니다. 편집한 모델을 원본 경계에 다시 맞춰 늘리는 방식으로 차이를 숨기지 않습니다. 원래 목표 폭/픽셀 변환을 유지합니다. 비교값은 전면 윤곽 IoU와 연결된 개구부 중심 오차(mm)입니다.

이 값은 추출 윤곽·영역과 결과 사이의 내부 일관성입니다. 독립적인 도면 정확도·고증·제작 승인 점수가 아닙니다. 미관찰 후면·측면·지붕 교차선의 원본 일치도를 검사했다고 표시하지 않습니다.

로컬 작업은 Web Worker에서 진행합니다. 최대 검사/보완 횟수는 기본 3회, 설정 1~5회이고 시간 한도는 15초입니다. 외부 AI 요청 수·한도는 이 경로에서 모두 0입니다. 결과가 충분히 일관되면 일찍 종료합니다. 실패·시간 종료·취소를 완료로 바꾸지 않고, 중간 최선의 결과가 있으면 그 상태로 보존합니다. 생성형 AI로 3회 재평가·수정하는 루프는 실제 연결 전입니다.

수정 요청은 선택 요소의 좌우 mm 이동·높이 조절을 해석하는 로컬 규칙입니다. 범용 자연어 AI 편집이 아닙니다. 지붕 낮추기는 선택 패널의 월드 높이 이동이며 건물 전체 지붕 재설계는 아닙니다. 지원하지 않는 표현은 적용하지 않습니다. 변경 전 형상은 최대 10개 보관합니다.

## 형상 검사

- 유효한 숫자와 크기/재료 한도, 요소 ID 중복.
- 다각형 자기 교차·면적 퇴화.
- 개구부의 부모 벽 관계, 벽 외부 개구부, 같은 벽의 개구부 겹침.
- 직사각형 개구부 범위와 프레임·여유를 만들 수 있는 최소 크기.
- 동일 배치 평면 패널의 겹침.

동일 배치가 아닌 임의의 3D 패널 간 간섭, 조립 접합부·구조 강도·휨은 검사하지 않습니다. 검사 통과와 실물 조립 확인은 별개입니다.

## 화면과 파일의 일치

`projectParts → compileDesign`이 만드는 하나의 부품 목록을 화면·부품 표·SVG·DXF·STL·JSON이 공유합니다. 벽 개구부는 polygon-clipping으로 빼고 프레임과 투명판을 별도 생성합니다. local outline은 같은 변환으로 조립합니다. SVG/DXF는 mm의 닫힌 윤곽, STL은 mm 좌표입니다. 조립 STL은 Z-up이고 베이스 하단을 0에 맞춥니다.

모형 화면은 Y-up입니다. 제조용 재료 두께를 실제 건물 치수처럼 80으로 나누지 않습니다. 절단 폭 보정·조인트·네스팅은 적용했다고 표시하지 않습니다. 추정 모델은 목표 폭으로 파일명을 만들고 미확인 1:80을 붙이지 않습니다.

## 저장과 복원

기존 localStorage 키와 IndexedDB 원본 저장소를 유지합니다. v1의 치수·자료·실물 기록을 읽고 v2 형상·이력을 추가합니다. 메타데이터 JSON에는 이미지 바이트나 일시적인 blob URL을 넣지 않습니다.

ZIP에는 project.json과 실제 원본 파일을 담고 파일별 SHA-256·길이를 확인합니다. 허용 경로·파일 개수·압축 해제 크기를 검사합니다. 복원은 새 자료 ID를 사용하고 형상·이력의 sourceId를 함께 바꿔 기존 파일을 덮어쓰지 않습니다. 실제 원본이 없으면 전체 백업을 성공으로 꾸미지 않습니다. 원본이 없는 메타데이터 JSON만으로는 다른 기기에서 사진이 복원되지 않습니다.

## 아직 남은 작업

- 공식 문서 확인 이후 실제 앱 승인·ChatGPT plan usage 인증·계정 모델 목록·이미지/구조화 호출.
- 생성형 AI 의미 해석과 근거 있는 외부 검색, 실제 요청 예산을 가진 AI 재평가 루프.
- 여러 입면의 좌표 정합, 다중 매스·교차 지붕의 사진 기반 공간 복원, 정확한 원근 보정.
- 창호 상세 형식, 곡면·장식, 접합부 설계·전체 간섭·가공 보정 및 실물 시험.

미연결 기능의 테스트는 모의 응답 검증이며 실제 AI 처리의 증거가 아닙니다. 초기 수용 검사는 합성 이미지의 실제 픽셀 입력을 사용합니다. 첨부된 임피역 원본 도면 전체의 정확한 3D 복원을 검증했다고 보고하지 않습니다.
