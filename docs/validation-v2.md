# v0.2 검증 기록

## 실행 결과

- Node.js 24.19.0 환경에서 타입 검사와 `npm run build -- --base=./ --logLevel warn` 성공.
- `npm test`: 26개 통과, 실패 0, 건너뜀 0.
- 배포 빌드를 서비스하는 Express에서 `npm run test:e2e`: 14개 통과, 실패 0.
- 3D 번들 크기에 대한 Vite 경고는 남아 있습니다. 오류를 숨기거나 검사 기준을 바꾸지 않았습니다.

## 직접 확인한 기능

- 서로 다른 실제 합성 이미지 픽셀 입력으로 개구부 수 2개/4개가 다른 형상·부품 수를 생성.
- 다중 봉우리와 평지붕의 외곽 차이, 목표 폭 300 mm, 실제 크기 미확인 표시.
- 자기 교차·NaN·중복 ID·벽 밖 개구부·개구부 겹침·동일 배치 패널 중복 검출.
- 하나의 창호 수정 후 다른 잠긴 창호와 부모의 월드 배치 보존, 이전 형상 복원.
- 새 패널 메시의 삼각형 변 쌍 검사, 동일 부품 데이터에서 SVG/DXF/STL/JSON 생성.
- SVG/DXF/STL/JSON을 다운로드 후 다시 읽어 mm 단위·부품 수·유효 내용을 검사.
- 원본 포함 ZIP 다운로드·다른 브라우저 컨텍스트에 복원·원본 PNG 확인·새 자료 ID 부여.
- 두 페이지 PDF 중 2쪽을 실제 래스터화해 4개 개구부와 페이지 근거를 생성.
- 빈 이미지 실패 시 이전 형상 보존, 진행 중 작업 취소, 모바일 가로 넘침 없음.
- 기존 CSV·수동 생성·원본 IndexedDB·v1 JSON 작업의 회귀 검사 통과.

## 실제로 검증하지 않은 사항

- 실제 ChatGPT 로그인·워크스페이스 동의·모델 목록 조회·이미지 생성형 AI 요청.
- 원격 앱의 SIWC 승인 또는 오픈소스/개인 실행 적격성.
- 첨부된 임피역 원본 11장 전체의 정확한 공간 복원.
- 전체 3D 간섭·강도·맞물림·kerf 보정·실물 가공·조립.

AI 응답 완료·중단·거부·과금 차단 검사는 모의 응답/미연결 로컬 엔드포인트 검사입니다. 합성 이미지 검사는 실제 브라우저/이미지 픽셀 연산이며 실제 생성형 AI 호출의 증거가 아닙니다. 내부 윤곽 겹침 비율을 독립적인 도면 정확도 점수로 취급하지 않습니다.

공식 SIWC 문서의 실제 열람 결과와 현재 앱의 미연결 사유는 [chatgpt-connection.md](chatgpt-connection.md)에 기록합니다. 운영 주소의 배포 후 검사는 아래 기록과 별도 JSON에 남깁니다.
