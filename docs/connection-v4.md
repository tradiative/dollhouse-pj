# v4 — 본인 전용 실행 경로와 실제 검증 상태

2026-10-24 (한국 시간), 앱 0.4.0. 이전 원격 서비스 신청 안내를 대체하는 현재 결정 기록입니다. 실제 ChatGPT 이미지 호출은 아직 **0건**입니다.

## 실행 결정

우선 후보는 **조건을 충족하는 OSS 앱을 대표님 전용 VM에서 실행**하는 경로입니다. 기존 Pages 주소는 입구로 유지합니다. 사용자에게 제공하는 원격 서비스의 참여 대기 명단과 이 경로를 동일하게 취급하지 않습니다.

확인한 사실:

- [공식 OSS 개요](https://developers.openai.com/siwc/token-sharing-open-source)는 같은 사용자·워크스페이스가 여러 호스트에서 한 등록을 사용할 수 있다고 설명합니다.
- [공식 Self-hosted VMs](https://developers.openai.com/siwc/token-sharing-open-source/self-hosted-vms)는 OSS 앱을 원격 VM에서 실행할 때 PC에서 같은 앱으로 새 OAuth를 완료하고 보호된 자격 증명을 SSH 등으로 이전하며, VM만 갱신하도록 안내합니다. 이전된 세션의 서버별 사용량 귀속·해제는 아직 제공되지 않습니다.
- [Request a client ID](https://developers.openai.com/siwc/request-client-id)는 일부 상용 파트너의 대기 명단입니다. 등록·신청·승인·모델 사용 권한은 서로 다른 상태입니다.
- [모델·요청 문서](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference): 계정별 `/v1/models`, 공식 `/v1/responses`, `store:false`, `stream:true`, 최종 `response.completed`. [UI 문서](https://developers.openai.com/siwc/ui-ux-guidelines)의 실제 사용량 관리 주소는 `https://chatgpt.com/settings/usage`입니다.
- 위 문서는 이번 작업에서 HTTP 200으로 열었습니다. 이 앱의 계정 승인이나 실제 호출 성공을 뜻하지 않습니다.

적용 판단: 코드가 적절하게 OSS로 제공되고 본인·동일 워크스페이스 전용으로 운영된다면 문서의 자가 서버 절차를 우선 적용할 근거가 있습니다. 다른 고객에게 운영자 사용량을 제공하는 서비스로 확장하는 허가를 뜻하지 않습니다. 라이선스 지정만으로 공급자의 모든 적격 조건을 충족했다고 확정하지 않습니다.

미확인: 자체 코드의 OSS 허락 결정, 실제 사용자·워크스페이스의 동의와 plan scopes, 계정별 이미지 입력 지원, 실제 모델 요청, 서버 호스팅·실제 주소·요금. 개인 서버도 아직 배포하지 않았습니다. 현재 환경의 공식 폼 접속 제한은 계정 거절이 아닙니다.

## 저장소 전체 라이선스 검토

변경 전 추적 파일 70개와 관련 README·문서·설정·소스 고지 및 전체 Git 파일 목록을 조사했습니다. 기존 공개 사례·자료의 이용 표시는 별도로 확인했습니다. 결과:

- README·과거 연결 문서는 자체 코드 라이선스를 바꾸지 않았다고 명시합니다. `package.json`은 `private:true`이며 자체 `license` 항목이 없습니다. `private`는 npm 게시 방지 설정으로 OSS 허락이 아닙니다.
- `public/THIRD-PARTY-NOTICES.txt`는 의존성에만 적용된다고 명시합니다. MIT인 일부 라이브러리와 Apache-2.0인 PDF.js, 별도 글꼴 고지는 자체 앱 전체를 OSS로 만들지 않습니다.
- 공개 임피역 사례는 국가유산청 자료의 별도 출처·공공누리 표시를 가집니다. 사용자 사진·도면·브랜드에 코드 라이선스를 소급 적용하지 않습니다.
- 따라서 단순히 `LICENSE` 파일이 없다는 이유만으로 판단한 것이 아니라, **자체 앱 재사용을 허락한 기존 결정이 확인되지 않은 상태**입니다.

검토 가능한 변경안: [license-proposal.patch](license-proposal.patch). 앱 코드·기술 문서를 MIT로 제공하고, 사용자 자료·건축 도면·사진·출력물·브랜드·기존 제3자 고지는 별도 권리로 남깁니다. 타인은 고지를 유지하며 앱 코드를 복제·수정·배포·상업 재사용할 수 있습니다. **아직 적용하지 않았으며 `LICENSE`·`LICENSING.md`·`package.json.license`는 변경하지 않았습니다.** 이 결정은 저작권자의 승인 대상입니다.

## 준비한 실행부

현재 사이트 → 별도 HTTPS 본인 작업실 → 대표님 선택 이미지 → 공식 Responses → 공통 형상·파츠 엔진. 두 출처의 브라우저 자료는 자동 동기화하지 않습니다. 초기에는 기존의 원본 포함 백업 ZIP을 보호된 작업실에서 가져옵니다. 공급자 토큰을 Pages에 넘기지 않습니다.

`deploy/personal-vm/`은 개발자용 배포안입니다. 새 호스팅 계약·배포는 실행하지 않았습니다. TLS 프록시만 외부에 노출하며 Node 포트를 공개하지 않습니다. 자격 증명 볼륨은 코드와 분리합니다. runtime·importer의 파일 잠금으로 동시 갱신·실행 중 덮어쓰기를 차단합니다. 비정상 종료로 남은 잠금은 개발자가 프로세스 종료를 확인하고 복구해야 합니다.

서버는 운영 형태 검토 표시·실제 HTTPS origin·보호된 저장소가 없으면 시작하지 않습니다. 별도 API 활성화와 개인 VM 모드를 함께 허용하지 않습니다. 단일 소유자 비밀번호(scrypt)·8시간 HttpOnly/Secure/SameSite=Strict 세션·Host/Origin/CSRF·로그인 시도 제한을 적용합니다. 계정 가져오기로 소유자를 바꿀 수 없습니다. 초기 소유자 기록이 없으면 원격 최초 가입을 받지 않습니다.

PC 연결 도구(`server/connector.ts`)는 실제 PC loopback 리스너를 먼저 열고 공식 OAuth를 시작합니다. 개발자가 **새로 준비한 이 앱 전용 SSH 키와 확인한 서버 호스트 키**만 사용합니다. `BatchMode`, `IdentitiesOnly`, `IdentityAgent=none`, `StrictHostKeyChecking=yes`이고 토큰은 SSH stdin으로만 보냅니다. 임의의 기존 SSH agent·ChatGPT 쿠키·Codex 캐시를 읽지 않습니다. 개인키·대상 서버 설정은 공개 꾸러미에 없습니다.

같은 앱에서 검증한 새 로그인만 이전합니다. 대상 VM host ID는 먼저 생성·보존합니다. PC는 전송 전에 갱신을 잠그며, 수신 확인 후 PC의 토큰을 삭제합니다. 수신 확인이 끊기면 자동으로 PC 갱신을 재개하지 않습니다. 같은 이전 ID·해시만 재확인할 수 있으며 대상 서버는 이미 갱신한 토큰을 재수신한 옛 값으로 덮어쓰지 않습니다. 서버 importer는 공개 HTTP 경로로 제공하지 않으며 실행부를 중지하고 실행합니다. 최초 이전은 10분 안에 완료해야 합니다.

SSH 계정의 강제 명령·최소 권한 및 최초/재연결 중지·시작은 실제 호스트에 맞춰 개발자가 준비·검증해야 합니다. Windows/macOS의 실행기·새 전용 키 ACL·실제 SSH 이전은 아직 검증하지 않았습니다. 공개 다운로드는 **개발자 실행 패키지**이며 대표님이 설치·설정해야 하는 제품으로 안내하지 않습니다. `node --import tsx server/connector.ts <개발자가 준비한 설정>` 경로는 개발자용입니다.

## 실제 사용·비용 상태

첫 PC 인증과 공식 동의는 대표님 본인이 해야 합니다. 그 전에는 ChatGPT 계정 연결·이미지 호출·형상 연동을 실제로 검증할 수 없습니다. 본인의 작업실 비밀번호는 PC 연결 도구에서 정하며 채팅·Git에 넣지 않습니다. 이후 서버 갱신은 자동, 세션 해제·권한 만료 시 같은 연결 도구로 재연결합니다. 개발자가 OS·호스트·백업·TLS·키와 재연결 절차를 유지합니다.

| 비용 | 현재 상태 |
| --- | --- |
| ChatGPT 요금제·크레딧 | 실제 실행 시 해당 사용량 소비. 현재 실계정 요청 0건. 남은 잔액 조회·무료·무제한 보장 없음 |
| 일반 API 별도 과금 | 비활성, 자동 전환 없음 |
| 실행부 운영비 | 호스트 미선택·미배포. 무료 할당·만료·저장소·전송·초과 요금 미확정. 기존 Pages 무료 정적 호스팅이 GPT 실행 서버까지 포함하지 않음 |

현재 승인 범위에서 코드·실행 패키지·보안 검사·정적 안내 배포는 진행합니다. 코드 OSS 허락과 실제 서버 비용·계정 동의에 종속된 활성화는 보류합니다. 실제 요금 조건이 확인되지 않은 호스팅을 무료라고 결정하거나 결제·계정을 생성하지 않았습니다.

## 다음 사용자 결정 하나

준비한 MIT 변경안의 적용 여부입니다. 사용자 자료를 제외하고 앱 코드의 상업 재사용까지 허용하는 결정이므로 자동으로 적용하지 않습니다. 결정 후 실제 호스트의 조건을 확인하고, 개발자가 대상이 지정된 연결 도구를 준비한 다음 본인 로그인·동의를 안내합니다. 지금 작동하지 않는 로그인 버튼이나 미배포 주소를 제공하지 않습니다.
