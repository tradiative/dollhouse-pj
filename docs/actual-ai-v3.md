# v3 진행 기록과 실제 AI 연결 결정안

## 현재 판정

v0.3은 **부분 구현**입니다. 공개 URL에서 실제 ChatGPT 로그인→이미지 요청→모델→파일의 연결은 아직 미실시입니다. 모의 공급자 통과와 도면 검토 사례를 M1 또는 전체 완료로 올리지 않습니다.

이유를 구분합니다.

- 미구현이었던 부분: 공식 개인 OAuth, 계정 모델 조회, 실제 요청을 시작하는 화면, 스트림 완료 처리와 다중 자료 프로그램 생성. 이번 코드에 구현했습니다.
- 호스팅 조건: GitHub Pages는 정적 호스팅이며 이 Express 실행부가 작동하지 않습니다. 현재 원격 앱의 구독 사용량 승인은 확인되지 않았습니다.
- 사용자 조건: Pro라는 답변은 받았지만 이 앱에서 로그인·워크스페이스·모델 권한·이미지 요청을 실제 검증하지 않았습니다. 계정이 거부됐다고 단정하지 않습니다.
- 오픈소스 조건: 공개 저장소만으로 적격 OSS라고 판단하지 않았고 자체 라이선스도 바꾸지 않았습니다.

## 준비한 두 실행 경로

| 경로 | 사용 경험·비용 | 구현·남은 절차 |
| --- | --- | --- |
| 기존 URL 유지 | 현재 웹 주소 유지. 별도 API 과금 OFF. 실행부 호스팅 조건·비용은 선택 전 확정하지 않음 | 원격 앱 승인과 보호된 원격 실행부가 필요. [공식 관심 등록](https://openai.com/form/sign-in-with-chatgpt-interest/)은 사용자/사업자의 신청 단계이며 대신 제출하지 않음 |
| 개인 PC의 브라우저 | PC에 설치된 개인 실행부를 브라우저로 사용. 별도 API 과금 OFF. 현재 사이트를 자동 전환하지 않음 | 공식 loopback OAuth·모델·요청 코드를 구현. 사용자의 실행 형태 선택, OS에 맞는 배포 패키지와 실제 공식 동의·모델 검증 필요 |

일반 API는 별도 비용이므로 사용자가 선택하기 전 활성화하지 않습니다. 사용자에게 토큰·쿠키 복사, 서버 명령·포트 설정을 요구하지 않습니다. 이 클라우드의 loopback을 사용자 PC의 콜백으로 안내하지 않습니다.

현재 다음 결정은 **기존 URL을 유지하며 원격 승인 경로를 준비할지, 개인 PC 실행 대안을 우선할지** 하나입니다. 선택 전 공개 URL을 유지합니다.

## 구현과 검증의 경계

- `TRADIATIVE_CHATGPT_MODE=personal-local`에서만 서버가 127.0.0.1에 바인딩하고 개인 OAuth를 활성화합니다. 기본값은 disabled입니다.
- 모델 권한이 확인되면 최초 이미지 요청을 실행할 수 있습니다. 실제 요청 완료 플래그를 먼저 요구하지 않습니다.
- 모델 카탈로그는 사용자 토큰으로 조회한 목록이며 하드코딩하지 않습니다. 로그인만 완료된 상태와 모델 권한·이미지 요청 완료를 구분합니다.
- 계정당 보호된 등록/인증 기록을 쓰며 이 초기 개인 실행 UI는 단일 등록을 재사용합니다. 여러 계정 전환 UI는 아직 제공하지 않습니다.
- 공급자 이벤트가 최종 완료된 뒤 JSON·프로그램·형상 검사까지 통과해야 화면에 적용합니다. 구조 오류 재요청은 최대 3회·90초입니다. 원본 이미지 렌더를 AI에 다시 보내는 시각 교정은 미구현입니다.
- 취소·한도·거부·중단은 이전 모델을 보존합니다. 다른 유료 경로로 전환하지 않습니다.
- 외부 검색은 연결하지 않았습니다. 실제 열람하지 않은 링크를 AI 근거로 허용하지 않습니다.

## 임피역 자료와 결과

기존 첨부 도면 11장과 국가유산청 공개 미리보기의 평면·정면·배면·좌우측을 대조했습니다. 앞·뒷면의 좌우 반전을 공통 구조로 대응시켰습니다. 긴 본체 지붕과 그에 직교하는 높은 박공, 후면 돌출부·부속부·개방 차양·주출입구 차양을 6개 구조 참조로 구성했습니다. 형상 요소 44개, 제작 검토 파츠 64개입니다.

분석은 이 개발 대화에서 수행했습니다. **웹앱의 실제 GPT 이미지 API 생성 결과가 아닙니다.** 치수·창호·지붕 접합의 정확한 복원이나 실물 제작을 완료한 결과도 아닙니다. 공개 사례 ZIP에는 500×354 JPEG 웹 미리보기 4개와 출처·해석 범위 파일이 있습니다. 사용자 고해상도 원본 11개·CAD 원본은 포함하지 않습니다.

4개 자료의 상세 페이지를 각각 열어 공공누리 제1유형 표시를 확인했습니다. 출처는 국가유산청 국가유산 디지털 서비스, 국가등록유산 군산 구 임피역입니다. 사례와 제작 파일에 실제 출처와 단순화 항목을 기록합니다. 저장소 자체 라이선스와 자료 이용 표시를 혼동하지 않습니다.

후면 차양·낮은 부속부의 경사, 간판·굴뚝·창살·가새, 정확한 창호 수치가 남아 있어 이 사례는 부분 성공입니다. 단순한 일반 집으로 대체한 결과를 도면 복원 성공으로 표시하지 않습니다.

## 공식 근거

2026-10-24 개발 중 공식 [개요](https://developers.openai.com/siwc/token-sharing-open-source), [로그인](https://developers.openai.com/siwc/token-sharing-open-source/sign-in), [모델·요청](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)을 HTTP 200으로 다시 읽었습니다. 원격 관심 등록 양식 자체는 이 환경의 호스트 허용 목록에서 차단되어 열지 못했고 제출하지 않았습니다. 양식 승인이나 계정 권한이 확보됐다고 보고하지 않습니다.
