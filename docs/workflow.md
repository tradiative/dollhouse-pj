# 작업 프로세스

현 버전의 데이터·검사·저장·지원 범위는 [engine-v2.md](engine-v2.md), ChatGPT 연동의 확인 결과와 남은 인증 단계는 [chatgpt-connection.md](chatgpt-connection.md)에 기록합니다.

자료 첨부 → 목표 크기 선택 → 관찰 입면의 브라우저 윤곽 추정 → 미관찰 깊이·후면 보완 → 원본 투영·근거 대조 → 요소별 수정·잠금 → 수치 검사 → 같은 형상에서 부품과 파일 생성 → 실물 시험 기록 순서로 진행합니다.

실제 AI가 연결되면 같은 형식의 가변 요소로 반환받고, 형식·범위·관계 검사 후 적용합니다. ChatGPT 인증이 미확인인 지금은 이 단계가 완료됐다고 표시하지 않습니다. API 오류·권한 없음·한도·중단은 실패 또는 제한 상태로 남기며 유료 경로로 넘기지 않습니다.

디지털 검사 통과는 원본 일치나 실물 조립 완료를 대신하지 않습니다. 관찰·추정·설계 보완과 사용자 확인·실측 확인을 별도로 유지합니다.
