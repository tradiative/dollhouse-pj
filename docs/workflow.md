# 건축 모형 제품화 프로세스 v0.1

## 공통 원칙

설계 기준을 하나의 데이터로 관리하고 2D 도안·3D 부품·치수표를 같은 값에서 생성합니다. 실제 치수는 mm, 모형 치수는 실제 치수 ÷ 축척입니다. 재료 두께·여유는 모형의 실제 제작 값이므로 축척으로 나누지 않습니다.

사진에서 읽은 치수, 사람이 직접 입력한 치수, 실물 제작 적합성은 서로 다른 확인 대상입니다. AI 판독 결과를 생성기에 바로 넣지 않고 제안 → 원본 대조 → 사용자 확인의 순서를 거칩니다. 모든 다운로드의 상태는 현재 버전에서 `검토용`으로 고정합니다.

## 1. 자료 수집

**입력:** 외관 사진, 치수 도면, 참고 문서, 측정 기록. 참조 자료의 재현 시기·권리·실측 여부는 프로젝트 담당자가 별도로 확인합니다.

**자동 처리:** 지원 파일 분류·파일 크기 제한, 브라우저 원본 보관, TXT·CSV의 명시된 치수 읽기. 서버 키가 있으면 명시적 분석 요청 시 OpenAI로 PNG·JPG·WEBP·텍스트를 보냅니다. 서버는 구조화된 응답, 지원 치수 필드, 양수·유한 숫자, 출처 ID를 검증합니다.

**사용자 확인:** 읽은 숫자, mm 단위, 실제 건물 치수 여부, 출처. 기준 길이가 없는 사진만 있으면 정확한 축척을 확정할 수 없습니다. 현재 버전은 실루엣의 자동 추정·포토그래메트리를 수행하지 않습니다.

**출력:** 원본 목록과 `{field, value, evidence, sourceId, confidence}` 형태의 미확정 치수 제안.

## 2. 설계 기준

**입력:** 실제 너비·깊이·벽 높이·지붕 높이·창문과 문 치수, 축척, 재료 두께, 절단 폭, 조립 여유.

**자동 처리:** mm 환산, 유효 범위 검사, 창문·출입문과 벽 경계 사이 간격 확인, 모형 크기와 미리보기 갱신. 현재 축척 범위 1:10~1:500, 모형 한 변 최대 2,000 mm, 벽체·지붕 두께 0.5~10 mm입니다.

**사용자 확인:** 원본 치수 대조 체크. 등록 자료가 없으면 확인할 수 없습니다. 치수 변경 시 원본 확인과 실물 시험 기록을 초기화하며, 기존 부품 생성 서명은 불일치 상태가 됩니다.

**출력:** 하나의 `Dimensions` 설계 기준과 확인 상태. kerf는 향후 CAM 보정을 위한 기록이며 형상을 변경하지 않습니다. 창틀 외곽에는 편측 조립 여유가 적용됩니다.

## 3. 부품 모델링

**입력:** 유효한 설계 기준.

**자동 처리:** 직사각 평면·박공지붕을 벽체·지붕·베이스·창틀·투명판·문으로 생성. 부품마다 ID·재료·두께·폐곡선·구멍·배치 변환을 지정합니다. 정렬된 개구부의 삼각분할에서 생기는 T 접합을 분할해 개별 부품 STL의 닫힌 경계를 유지합니다.

**사용자 확인:** 3D와 분해 보기, 부품 크기, 재료, 건축적 특징. ‘부품 생성’은 현재 치수의 서명을 기록하는 작업이며 승인 절차를 대신하지 않습니다.

**출력:** 34개 부품의 기하 데이터와 현재 설계 서명. 형상 생성기는 자유 형상 건축물을 해석하는 AI가 아니라 재현 가능한 파라메트릭 규칙입니다. 구조를 확장할 때는 형상 유형별 생성기를 추가합니다.

## 4. 검수

| 항목             | 검사 방식 | 통과 조건                                         |
| ---------------- | --------- | ------------------------------------------------- |
| 축척·단위 일관성 | 자동      | 모든 필수 치수와 제작 값이 유효 범위 안에 있음    |
| 윤곽·개구부      | 자동      | 유효 형상과 문·창의 경계·간격 규칙 만족           |
| 원본 치수 대조   | 사용자    | 자료가 등록되어 있고 원본 대조 체크가 기록됨      |
| 부품 버전 일치   | 자동      | 생성 당시 설계 서명과 현재 설계 서명이 같음       |
| 재료·조립 확인   | 사용자    | 시험 가공 기록이 존재하고 실물 확인 체크가 기록됨 |

준비도는 위 다섯 항목의 통과 비율입니다. AI의 자신감이나 실제 제품의 완성도 비율을 뜻하지 않습니다. 전체 3D 간섭·강도·조인트·접착 적합성은 자동 검사하지 않습니다. 부분 겹침이 의도된 접착 구간인지 여부도 별도 실물 검토가 필요합니다.

## 5. 문서화·내보내기

**SVG:** 실제 mm 크기, 모든 부품의 윤곽·구멍·부품 번호·재료·두께, 검토용 표시. 큰 부품은 시트 폭을 확장합니다. 출력할 때 ‘페이지에 맞춤’을 사용하지 말고 100% 배율과 기준 길이를 확인합니다.

**DXF:** R2000, mm 단위, 닫힌 LWPOLYLINE, 부품별 레이어. CNC·레이저 설정은 가공업체에서 정해야 합니다.

**STL:** mm 좌표, 개별 부품은 XY에 평평하게 배치, 전체 조립체는 Z-up. 색상·재료·단위는 STL에 보존되지 않습니다.

**JSON:** 버전·설계 기준·자료 목록·원문 치수 텍스트·부품 데이터·검수 기록. 이미지 바이트와 일시적 blob URL, 서버 비밀은 포함하지 않습니다. 가져오면 원본·실물 확인과 생성 상태를 다시 검토해야 합니다.

**검수 문서:** 한국어 인쇄 화면에 설계 기준·참고 자료·부품 목록·검수 결과·수정 시각을 포함합니다. 브라우저에서 PDF로 저장할 수 있습니다.

## 다음 제품화 범위

실제 한 건물의 정면 벽·창틀·투명판을 시험 제작해 가공 규칙을 정한 다음, 조인트 생성과 간섭 검사를 추가하는 순서가 적절합니다. 비정형 형상은 사람이 확인한 윤곽을 입력할 수 있는 편집기와 유형별 모델 생성기로 확장합니다. 다중 사용자 운영은 인증·권한·서버 파일 보관·원본 및 수정 이력·AI 사용량 제한을 먼저 갖춰야 합니다.
