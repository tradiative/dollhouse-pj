## 실제 실행과 모의를 구분

OAuth 검사는 자체 테스트 RSA 키로 서명한 모의 ID 토큰과 모의 공식 응답을 사용했습니다. state·nonce·audience·서명·만료·거부·재사용 차단, 계정별 모델 목록, 직렬 갱신·회전 저장·권한 파일 모드, 스트림 중 한도·미완료·취소를 검사했습니다. HTTP 통합 검사는 다른 Origin/Host 차단 및 잘못된 구조 응답을 한도 안에서 수정하는 흐름을 검사했습니다. **실제 사용자 로그인이나 OpenAI 이미지 요청의 증거가 아닙니다.**

화면의 GPT 흐름 검사는 모의 공급자로 자료 2개 선택→요청→구조→모델→다운로드를 검사했습니다. 실제 이미지 요청 완료 플래그가 false인 최초 연결에서도 검증 요청을 시작할 수 있음을 확인했습니다. 과금 API로 전환하지 않았습니다.

로컬 이미지·PDF 검사는 실제 파일·픽셀 연산입니다. 이 역시 생성형 AI 요청으로 세지 않습니다.

## 실제 임피역 자료의 검토 사례

- 기존 사용자 첨부 도면과 공개 웹 미리보기 4개를 대조해 작성한 구조를 실제 엔진으로 컴파일했습니다.
- 긴 본체와 직교 높은 박공 및 후면 부속부를 6개 구조 참조, 44개 요소, 64개 파츠로 계산했습니다.
- 자기 교차·중복 ID·개구부 관계·지원 범위의 겹침 검사 통과. 부품별 STL·CSV·SVG·DXF·조립 STL을 같은 부품 목록에서 내보냈습니다.
- 실제 공개 미리보기 4개와 출처/범위 문서가 포함된 ZIP을 브라우저에서 복원했습니다. 새 자료 ID를 요소·덩어리 근거에 다시 연결했습니다.
- 부품 64개와 ZIP 내 STL 64개, JSON 부품 수, BOM 행 수를 대조했습니다.
- 3D 화면을 캡처해 직접 열어 확인했습니다. 화면과 파일은 검토용이며 실제 제작 승인이 아닙니다.
- 자료에는 표시가 흐리거나 다른 시점의 해석이 남습니다. 경사 차양·간판·굴뚝·창살·가새와 정확한 창호 치수는 미해결입니다.

T01~T12의 판정은 [actual-ai-v3.md](actual-ai-v3.md)에 있습니다. 전체 자동 AI 흐름은 미완료이며 M1·T02·T12 전체 통과로 보고하지 않습니다. 공개 주소의 배포 후 검사 결과는 별도 기록합니다.
