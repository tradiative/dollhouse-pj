# 웹 작업실 사용하기

1. ‘이미지·PDF 추가’를 눌러 자료를 올립니다. ‘분석할 자료’에서 한 입면을 선택합니다.
2. PDF는 페이지 번호를 고르고 ‘페이지 이미지 열기’를 누릅니다.
3. 목표 모형 폭을 정합니다. 기본은 300 mm입니다. 실제 건물 치수를 몰라도 진행할 수 있습니다.
4. 도면 테두리·표제란이 함께 잡히면 이미지에서 건물 부분을 드래그해 분석 영역을 지정합니다.
5. ‘이미지에서 외형 추정’을 누릅니다. 이 기능은 브라우저에서 실행하며 API 키가 필요 없습니다.
6. 원본 위 투영과 3D의 ‘정면도’를 비교합니다. 요소를 선택해 근거를 보고 잠금·이동·크기를 수정할 수 있습니다.
7. ‘부품 모델링 → 부품 생성 → 내보내기’에서 SVG·DXF·STL·JSON을 받습니다.
8. 사진·도면 원본과 변경 이력까지 보관하려면 ‘원본 포함 백업’ ZIP을 받습니다. 복원은 ‘백업 ZIP 가져오기’를 사용합니다.

현재는 단일 입면 윤곽을 깊이로 보완하는 검토용 모델입니다. 교차 지붕의 실제 3D 구조나 여러 도면의 자동 정합은 지원하지 않습니다. 실제 치수를 모르면 정밀 축척 복원으로 표시하지 않습니다.

공식 문서상 Plus·Pro 사용량 연결 경로는 있습니다. 현재 원격 앱의 승인·인증·모델 호출은 검증 전입니다. ‘ChatGPT로 설계하기’는 연결을 확인할 때까지 비활성입니다. 별도 API로 자동 과금하지 않습니다.

기존 CSV는 ‘자료 수집 → 자료 추가 → 자료 분석 → 제안 치수 반영’으로 계속 사용할 수 있습니다. 이 CSV 경로는 수동 치수 생성기이며 이미지 전체 형상을 복원하지 않습니다.
