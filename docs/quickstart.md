# 처음 사용하는 분을 위한 안내

## 접속 주소의 현재 상태

현재 앱은 Codex 클라우드 개발 머신의 3000번 포트에서 실행됩니다. 외부 브라우저에서 열 수 있는 공개 웹 주소는 아직 발급되지 않았습니다. 작업 화면 이미지는 웹사이트 접속 링크가 아닙니다.

클라우드 환경의 ‘게시’는 개발 환경의 설정과 파일을 저장하는 기능입니다. 웹사이트를 인터넷에 배포하는 작업과는 다릅니다. 실제 접속 URL은 별도의 웹 호스팅에 배포한 뒤 생깁니다.

## 가장 빠른 체험 순서

사이트에 접속한 뒤에는 기본으로 열리는 ‘임피역 본관’ 샘플에서 시작하세요. 사진이나 API 키 없이도 다음 흐름을 체험할 수 있습니다.

1. **설계 기준:** ‘건물 너비’를 `14400`으로 바꾸고 ‘모형 축척’을 `1:80`으로 설정합니다. 작업대 아래 모형 너비가 `180.0 mm`가 되는지 확인합니다. 원본과 대조하지 않은 치수는 확인 체크를 하지 않아도 됩니다.
2. **부품 모델링:** ‘부품 생성’을 누릅니다. 벽체·지붕·창틀·투명판·문·베이스 34개 파츠가 생성됩니다.
3. **3D 작업대:** 마우스로 드래그해 회전하고 스크롤해 확대합니다. 겹친 레이어 아이콘은 분해 보기입니다. 부품을 클릭하면 해당 항목을 볼 수 있습니다.
4. **검수:** 자동 검사 결과와 미확인 항목을 확인합니다. 실제로 가공·조립하지 않았다면 실물 시험 확인은 미확인으로 남겨둡니다.
5. **파일 내보내기:** SVG 도안이나 STL 모델을 내려받습니다. ‘검수 문서 인쇄’에서 브라우저의 PDF 저장을 선택하면 문서를 보관할 수 있습니다. 파일은 검토용입니다.

## 실제 프로젝트로 사용하는 순서

1. 왼쪽의 **새 프로젝트 만들기**를 눌러 건축물 이름을 입력합니다. 기존 프로젝트는 JSON 백업으로 내려받습니다. 원본 사진은 JSON에 포함되지 않으므로 별도로 보관하세요.
2. **자료 수집 → 자료 추가**에서 사진·도면·치수 기록을 첨부합니다. 파일당 최대 10 MB입니다. 자료의 썸네일을 누르면 원본을 확인할 수 있습니다.
3. 치수가 들어 있는 CSV·TXT는 **자료 분석**으로 제안을 읽을 수 있습니다. 사진 판독은 AI 서버 연결이 필요합니다. PDF·DXF는 원본 참고 자료로 사용하며 자동 판독하지 않습니다.
4. **설계 기준**에 실제 건물의 치수를 mm로 입력하고 축척 `1:80`을 선택합니다. 합판 두께와 조립 여유는 실제 모형 제작 값으로 입력합니다. 예를 들어 실물 8,000 mm는 모형 100 mm이며, 구매할 합판 두께 1.5 mm는 그대로 1.5 mm입니다.
5. 원본을 대조한 항목만 확인한 뒤 **부품 생성 → 검수 → 내보내기**로 진행합니다. 치수를 바꾸면 기존 부품을 다시 생성하고 확인 상태도 다시 검토해야 합니다. 실물 시험 기록의 내용은 보존됩니다.

## 두 가지 배포 방식

### 브라우저 체험용

정적 웹 배포 파일에는 화면·3D 작업대·수동 치수 입력·CSV 읽기·검수·파일 내보내기가 들어 있습니다. 일반 정적 웹 호스팅의 사이트 루트에 배포하면 사용할 수 있습니다. `index.html`과 `assets` 폴더가 같은 사이트 루트에 있어야 합니다. HTML 파일을 더블 클릭하는 방식으로는 실행하지 마세요.

이 방식에서는 사진 AI 분석을 사용할 수 없습니다. 자료와 프로젝트는 접속한 브라우저에만 저장됩니다. 다른 기기나 사이트 주소로 바뀌면 JSON과 원본 파일을 함께 옮겨야 합니다.

### 사진 AI 판독까지 사용하는 전체 앱

Node.js 24를 실행할 수 있는 서버 호스팅이 필요합니다.

- 설치: `npm ci`
- 빌드: `npm run build`
- 실행: `npm start`
- 포트: 호스팅이 제공하는 `PORT` 환경 변수를 사용합니다. 기본값은 3000입니다.
- 선택적 AI 비밀: 서버 설정에 `TRADIATIVE_AI_KEY`를 등록합니다. 키를 채팅이나 프런트엔드에 넣지 마세요.

이 버전은 직사각형 평면·박공지붕의 작업용입니다. 사진만으로 자유 형상의 건축물을 자동 복원하는 기능, 사용자 로그인과 공동 작업 기능은 아직 포함되지 않습니다.
