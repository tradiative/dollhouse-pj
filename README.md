# TRADIATIVE Studio

트레디에이티브를 위한 건축 모형 제작 웹 작업실의 첫 버전입니다. 참고 자료를 등록하고, 실제 건축물의 치수와 제작 규칙을 정해 2D 도안·부품별 3D 파일·검수 문서를 만듭니다.

## 실행

Node.js 24와 npm을 사용합니다. 클라우드 작업은 이미 격리되어 있으므로 `/workspace/dollhouse-pj`의 기존 체크아웃을 사용합니다. 별도 Git worktree를 만들 필요가 없습니다.

```sh
cd /workspace/dollhouse-pj
npm ci
npm run dev
```

개발 서버는 기본 3000번 포트에서 실행됩니다. Vite와 Express가 하나의 프로세스에서 동작합니다.

```sh
npm run build       # TypeScript 검사 + 배포용 프런트엔드
npm start           # 빌드 결과를 Express로 서비스
npm test            # 축척·형상·STL·DXF·검수·데이터 검사
npm run test:e2e     # Chromium에서 실제 사용자 흐름 검증
```

E2E는 `/usr/bin/chromium`을 사용합니다. 다른 환경에서는 `CHROMIUM_PATH`를 지정하거나 Playwright 설정의 실행 경로를 변경합니다. `GET /api/health`에서 서버 상태와 AI 설정 유무를 확인할 수 있습니다. 이 응답에는 비밀 값이 포함되지 않습니다.

## 사용할 수 있는 기능

- **자료 수집:** JPG·PNG·WEBP·PDF·SVG·DXF·CSV·TXT 등록, 이미지·텍스트·PDF 원본 보기, 원본 내려받기. 파일당 10 MB 제한.
- **치수 읽기:** CSV·TXT의 `width,12800` 또는 `벽높이=3600 mm` 같은 명시 치수 추출. 샘플은 [examples/dimensions.csv](examples/dimensions.csv)를 참고하세요.
- **설계 기준:** 실제 mm 치수를 1:50·80·87·100 등으로 환산. 재료 두께, 절단 폭 기록값, 창틀 편측 여유를 별도로 관리.
- **3D 작업대:** 회전·확대·정면·분해 보기, 부품 선택, 전체 2D 윤곽 미리보기. 화면의 눈금은 현재 카메라 확대율에 맞춰 표시.
- **부품 생성:** 벽체 4개, 지붕 2개, 베이스 1개, 창틀 13개, 투명판 13개, 출입문 1개. 총 34개 파츠의 치수가 함께 갱신됩니다.
- **검수:** 축척·치수 범위·개구부 위치·버전 일치의 자동 검사와 원본 대조·실물 시험의 사용자 확인을 분리. 치수 변경 시 기존 확인과 실물 기록이 무효화됩니다.
- **내보내기:** mm 단위 SVG, R2000 DXF(부품별 레이어), 조립 STL, 개별 파츠 STL, 프로젝트 JSON. 브라우저 인쇄로 한국어 검수 문서를 PDF로 저장할 수 있습니다.
- **저장·복원:** 설계 기준과 기록은 localStorage, 원본 파일은 IndexedDB에 보관. 새로고침해도 같은 브라우저에서 다시 열립니다. 새 프로젝트를 시작하면 현재 프로젝트의 JSON 백업을 내려받습니다. JSON 가져오기는 치수·검수 확인 상태를 초기화합니다.

## 선택 기능: 사진 AI 분석

기본 작업 흐름에는 API 키가 필요하지 않습니다. 사진에서 명시된 치수 표기를 읽으려면 서버에 아래 설정을 주입합니다. 클라우드에서는 환경 설정의 비밀 항목을 사용하세요. 로컬에서는 `.env.example`을 참고해 Git에서 제외된 `.env`를 만들 수 있습니다. 서버가 시작할 때 `.env`를 읽습니다.

```dotenv
TRADIATIVE_AI_KEY=<보안 설정에서 주입>
TRADIATIVE_AI_MODEL=gpt-4.1-mini
```

키를 프런트엔드 코드나 `VITE_` 환경 변수에 넣지 마세요. 분석 버튼을 누를 때만 선택된 프로젝트의 지원 이미지·텍스트가 서버를 거쳐 OpenAI Responses API로 전송됩니다. `store:false`를 지정합니다. 이 설정만으로 서비스 제공자의 모든 보관 정책이 결정되는 것은 아닙니다. 실제 키가 없는 현재 환경에서는 유료 AI 호출이 실행되지 않았습니다.

AI는 보이는 실제 치수만 **미확정 제안**으로 반환합니다. 기준 길이가 없는 사진의 크기나 숨겨진 구조를 추정해 확정 치수로 등록하지 않습니다. 판독 근거·자료 ID를 표시하며, 사용자가 제안을 반영한 뒤 별도로 원본 대조를 확인합니다. PDF·SVG·DXF 자동 판독과 사진 기반 3D 복원은 구현 범위에 포함되지 않습니다. PNG·JPG·WEBP 또는 치수 TXT·CSV를 사용하세요.

## 제작 전 확인할 범위

이 버전의 형상 생성기는 **직사각형 평면·박공지붕·정해진 창문 배치**를 다룹니다. 임피역 화면은 기능을 설명하는 예시이며 실측 복원 도면이 아닙니다. 자유 형상 건물, 자동 조인트 설계, 전체 조립체 간섭 해석, 구조 강도 검증, 자재 절단 최적 배치는 아직 제공하지 않습니다.

모든 내보내기 파일은 **검토용**입니다. 검수율 100%는 등록된 항목에 대한 확인 기록이며 제작 승인이나 가공 보증을 의미하지 않습니다. kerf는 기록만 하고 절단 윤곽을 오프셋하지 않습니다. 가공업체가 재료별로 분리한 뒤 CAM에서 보정해야 합니다. 시험 가공과 조립 검증이 필요합니다.

개별 STL은 XY 평면의 부품을 +Z로 돌출한 mm 좌표입니다. 조립 STL은 Z-up, 베이스 하단 Z=0입니다. JSON 부품 배치 정보와 화면은 Y-up입니다. STL 자체에는 단위 메타데이터가 없으므로 가져올 때 mm를 선택하세요. 조립 STL은 별도 부품을 포함한 검토용 조립체이며 하나의 불리언 결합 메시가 아닙니다.

원본 파일은 JSON에 포함되지 않습니다. 다른 브라우저·기기로 옮길 때는 JSON과 원본 자료를 함께 보관하고 다시 첨부해야 합니다. 브라우저 데이터 삭제 시 로컬 원본과 설정도 삭제될 수 있습니다.

현재는 한 브라우저에서 사용하는 개발용 도구입니다. 계정 인증, 협업 권한, 서버 파일 보관·백업, 사용량 제한·과금, 감사 이력은 별도 제품화 작업이 필요합니다. AI 키를 설정한 채 인증 없이 공용 인터넷에 배포하지 마세요.
