# TRADIATIVE Studio 0.3.1

[공개 작업실](https://tradiative.github.io/dollhouse-pj/) · [원격 앱 승인 준비](https://tradiative.github.io/dollhouse-pj/connection/) · [v3 진행 기록](docs/actual-ai-v3.md)

건축물의 자료·근거·가변 모델·제작 검토 파츠를 관리하는 웹 도구입니다. 첫 실행은 빈 작업대이며 기존 브라우저 프로젝트는 보존합니다. 예시 집은 **예시 프로젝트 열기**, 실제 공개 도면을 대조해 작성한 임피역 사례는 **임피역 도면 검토 사례 열기**로 구분합니다.

**공개 사이트의 ChatGPT 구독 연결은 아직 미완료입니다.** 개인 실행용 공식 OAuth·모델 조회·이미지 요청·구조화 형상 생성 코드를 구현했으며 모의 공급자로 검사했습니다. 실제 사용자 로그인·구독 이미지 요청을 완료했다고 보고하지 않습니다. 별도 과금 API는 OFF이며 자동 전환하지 않습니다.

## 현재 사용할 수 있는 것

- 자료 첨부, PDF 페이지 열기, 목표 모형 폭(기본 300 mm) 설정.
- 로컬 윤곽·대비 추출: 한 입면을 분석하는 보조 기능입니다. GPT 해석·여러 자료의 자동 정합과 다릅니다.
- 복수 건물 덩어리, 서로 다른 지붕 방향, 교차 지붕의 상부 표면 절삭, 벽별 개구부, 요소 수정·잠금·되돌리기.
- 원본·근거·자료 버전 표시, 3D/정면/후면/좌우측 보기.
- 동일 형상에서 SVG·DXF·STL·JSON·CSV 부품표와 **제작 검토 꾸러미 ZIP** 생성. ZIP에는 부품별 STL과 mm 단위 안내가 포함됩니다.
- IndexedDB 원본을 포함한 전체 백업 ZIP 및 v1/v2 JSON 호환. ZIP 복원은 새 자료 ID를 사용해 기존 원본을 덮어쓰지 않습니다.

임피역 사례는 국가유산청의 공개 웹 미리보기 4개와 기존 첨부 도면을 대조한 검토용 해석입니다. 높은 박공을 앞·뒷면의 별개 건물로 중복하지 않고 하나의 직교 지붕으로 연결합니다. 일부 경사 차양은 평면으로 단순화했고 간판·굴뚝·창살·가새는 미구현입니다. 실제 GPT API 생성이나 실측 복원으로 소개하지 않습니다. 사례 안에 출처·공공누리 제1유형·미리보기 해상도 안내를 포함합니다. 저장소 자체의 라이선스를 변경하지 않습니다.

## AI 실행 경로

사용자는 기존 URL을 유지하는 원격 앱 승인 경로를 선택했습니다. [신청 준비 자료](docs/remote-approval.md)에 소개문·현재 데이터 처리·구성안과 미확인 항목을 정리했습니다. 실제 신청 제출·원격 승인·모델 요청은 아직 확인 전입니다. 개인 PC 전환 여부를 다시 묻지 않습니다.

- GitHub Pages에는 서버가 실행되지 않습니다. 원격 앱의 구독 사용량 승인과 보호된 실행부가 준비되기 전에는 공개 방문자에게 소유자 사용량을 제공하지 않습니다.
- 개인 실행 대안은 명시적 `TRADIATIVE_CHATGPT_MODE=personal-local` 설정에서만 활성화됩니다. **사용자 PC의** HTTP 127.0.0.1 화면과 콜백을 사용하며 이 모드의 서버는 loopback에만 바인딩합니다. 현재 클라우드를 사용자 PC의 콜백으로 제공하지 않습니다.
- `Continue with ChatGPT` → 사용자 동의 → **사용 가능한 모델 확인** → 자료 선택 → **ChatGPT로 설계하기**. 최초 요청은 실제 이미지 검증 완료 플래그가 없어도 실행할 수 있어 순환 조건이 없습니다.
- PKCE/state/nonce, 공식 JWKS 서명·issuer/audience/expiry/subject 검증, 소유자 전용 원자적 저장과 직렬 토큰 갱신을 구현했습니다. 플랫폼/Codex/ChatGPT 쿠키·기존 세션 토큰은 읽거나 복사하지 않습니다.
- 모델 목록은 공식 계정별 `/v1/models` 카탈로그를 사용합니다. 구독 요청은 `store:false`, `stream:true`로 보내며 `response.completed` 전에는 성공이 아닙니다. 최대 6개 선택 자료·3회 요청·90초·동시 1작업으로 제한하고 취소와 구조 오류 재요청을 지원합니다.
- 자연어 설계 요청과 기존 형상을 같은 요청에 전달하고 잠긴 요소를 보존합니다. 렌더를 AI에 재입력하는 자동 시각 교정·외부 검색은 아직 연결하지 않았습니다.
- 일반 API 경로는 별도 허용 설정·서버 키·매 요청의 과금 동의·동일 기기 조건을 모두 요구합니다. 사용자 선택 없이 활성화하지 않습니다.

원격 승인, 개인 실행 적격성, 실제 계정 권한은 코드만으로 확보되지 않습니다. 현재 배포 형태를 사용자의 선택 없이 로컬 전용으로 변경하지 않았습니다.

## 엔진과 제작 한계

`src/design/program.ts`는 상대좌표 건물 프로그램을 모델 mm 요소로 컴파일합니다. 정면은 +Z, 후면은 -Z, 오른손 Y-up이며 부품 로컬 XY를 +Z로 압출합니다. 직사각 덩어리·평면 박공/평지붕·직사각 창호를 지원합니다. `elements`가 화면·파일의 최종 형상이며 `masses`는 구조 추정의 참조 기록입니다.

실제 기준 길이가 없으면 정밀 1:80을 주장하지 않습니다. 실물 판재 두께를 축척으로 나누지 않습니다. 창틀 여유 외의 조인트·kerf 보정·전체 3D 간섭·강도·판재 두께의 지붕 접합·실물 조립은 미검증입니다. 모든 출력은 검토용이며 양산 승인이 아닙니다.

## 개발 환경

Node.js 22 이상(현재 24.19.0). 개발자가 실행을 담당합니다. 사용자에게 서버·포트·API 오류 분석을 요구하지 않습니다.

```sh
npm ci --cache /workspace/.cache/tradiative-npm --no-audit --no-fund
npm run dev
npm run build -- --base=./
npm test
TEST_BASE_URL=http://127.0.0.1:3306 npm run test:e2e
```

`npm start`는 빌드와 Express API를 함께 서비스합니다. `/api/health`, `/api/ai/status`로 준비 상태를 확인합니다. 기본 모드에는 인증 비밀 값이 없고 외부 AI 요청도 없습니다. 비밀 값은 VITE_ 변수·브라우저 저장·Git·로그·채팅에 넣지 않습니다.

원본 포함 ZIP은 파일당 10 MB·합계 60 MB, ZIP 내 메타데이터 8 MB, 직접 JSON 가져오기 2 MB, 요소 500개·윤곽 128점까지 지원합니다. 장기 보관에는 전체 백업을 사용하세요.

## 주요 코드

| 경로 | 역할 |
| --- | --- |
| `server/chatgpt.ts` | 공식 개인 OAuth·보호된 인증 저장·모델 카탈로그·구독 스트림 |
| `server/planRoutes.ts` | 동일 기기/출처·CSRF·요청 상한·이미지→구조→검사 |

| `src/design/aiClient.ts` | 화면의 자료 선택과 실제 요청 경로 |
| `src/design/compile.ts` | 동일 형상에서 모든 화면·출력용 부품 생성 |
| `src/design/deliverables.ts` | 부품표·제작 ZIP·부품별 STL·단위 안내 |
| `src/design/archive.ts` | 원본·근거·이력의 무결성 백업/복원 |

[v2 검증 기록](docs/validation-v2.md)은 이전 배포 기록입니다. v3의 실제 계정 검증과 혼동하지 않습니다. 의존성 고지는 `public/THIRD-PARTY-NOTICES.txt`와 글꼴 라이선스를 따릅니다.
