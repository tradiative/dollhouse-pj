# TRADIATIVE Studio 0.2

사진·도면 자료의 관찰 입면을 모형 mm의 가변 요소로 만들고, 근거와 함께 검토하는 웹 작업실입니다. 기존 수동 치수·CSV 작업과 저장 데이터를 유지합니다.

**현재 구현은 브라우저 이미지 추정입니다. ChatGPT 구독 사용량 연동과 실제 생성형 AI 이미지 요청은 검증되지 않았습니다.** 구독 연결이 실패해도 별도 API로 자동 전환하지 않습니다.

## 사용 흐름

1. **이미지·PDF 추가**로 자료를 첨부하고 분석할 한 입면을 선택합니다. PDF는 페이지를 선택해 이미지로 엽니다.
2. 목표 모형 폭(기본 300 mm), 깊이 추정 비율, 실제 판재 두께를 정합니다. 실물 기준 길이는 선택 사항입니다.
3. 필요하면 이미지에서 건물 영역을 드래그한 뒤 **이미지에서 외형 추정**을 누릅니다.
4. 원본 위의 입면 투영, 정면도, 관찰·추정·설계 보완 근거를 비교합니다. 요소별 이동·크기 편집, 잠금, 이전 형상 복원을 지원합니다.
5. **부품 모델링 → 부품 생성 → 내보내기**에서 SVG·DXF·STL·JSON을 받습니다. 원본과 이력까지 옮길 때는 **원본 포함 백업** ZIP을 사용합니다.

이미지만 추가한 상태에서는 기존 예시 집을 분석 결과로 표시하지 않습니다. 기존 치수 작업을 직접 원본과 대조해 확인한 경우에는 예전 수동 생성 경로를 계속 사용할 수 있습니다.

## 지원 범위와 한계

- 이미지의 연결 윤곽·대비·CAD 색상 경계로 입면 외곽과 개별 개구부 후보를 추출합니다. 고정된 창문 13개를 넣지 않습니다.
- 보이는 입면 윤곽을 가정 깊이로 연결한 외형과 후면을 만듭니다. 보완 창호는 관찰 결과와 별도로 기록합니다.
- 데이터 형식은 개별 평면 패널·벽·지붕·직사각형 개구부·장식을 표현합니다. 현재 로컬 추정기는 한 입면씩 처리합니다.
- **실제 교차 박공지붕의 3D 교차선, 여러 입면의 자동 정합, 원근 사진의 정확한 보정, 곡면·장식 복원, OCR 치수 판독은 미구현입니다.** 이 결과를 임피역의 도면 일치 복원 모델로 부르면 안 됩니다.
- 의미를 해석하는 생성형 AI나 외부 검색은 이 브라우저 경로에서 실행하지 않습니다. 흰 화면·판독 실패는 실패로 남기고 이전 결과를 보존합니다.
- 실제 건물 크기를 모르면 목표 모형 mm로 표시합니다. 실측 1:80이나 고증 완료를 주장하지 않습니다. 실제 재료 두께는 축척으로 나누지 않습니다.
- 윤곽·개구부·수치·ID·관계·중복 배치를 검사합니다. 전체 3D 간섭, 구조 강도, 조인트 가공, kerf 보정, 실물 조립은 검증하지 않습니다. 모든 출력은 검토용입니다.

## 개발 실행과 검증

Node.js 22 이상(검증 환경 24.19.0)을 사용합니다. 기존 체크아웃에서 작업하며 별도 worktree가 필요하지 않습니다.

```sh
npm ci --cache /workspace/.cache/tradiative-npm --no-audit --no-fund
npm run dev
npm run build
npm test
npm run test:e2e
```

`npm start`는 빌드 결과와 API 상태를 함께 서비스합니다. `PORT`로 개발용 포트를 바꿀 수 있습니다. `/api/health`는 준비 상태, `/api/ai/status`는 실제 AI 연결·검증 상태를 반환합니다. 원본 파일은 IndexedDB, 프로젝트 메타데이터는 기존 localStorage 키를 유지합니다.

## AI 연결과 과금

- 공식 문서에서 Plus·Pro의 구독 사용량 경로와 개인 실행용 공식 흐름을 확인했습니다. 원격 호스팅 앱은 별도 승인 조건이 있으며 현재 앱의 승인·사용자 인증·모델 권한은 미검증입니다. 저장소 공개만으로 적격 오픈소스 앱이라고 가정하지 않았고 저장소 라이선스도 변경하지 않았습니다.
- 로그인 쿠키·세션 토큰을 복사해 넣는 기능이 없습니다. 로그인 버튼이나 연결 상태를 성공처럼 꾸미지 않습니다. 남은 사용량을 임의 표시하지 않습니다.
- 기존 치수 전용 AI 요청은 비활성화했습니다. 브라우저 이미지 추정과 CSV/TXT 판독은 API 키 없이 동작합니다.
- 별도 API 경로는 기본 OFF이며 `TRADIATIVE_ALLOW_SEPARATE_API=true`, 서버의 기존 `TRADIATIVE_AI_KEY`, 요청별 `billingConsent:true`, 동일 기기의 개인 실행 조건을 모두 만족해야 실행됩니다. 현재 제품 화면에서는 이 유료 경로를 활성화하지 않습니다.
- API 출력은 완료 상태와 JSON 형식·수치·관계를 모두 검사합니다. 관찰이라고 분류해도 사용자 확인·실측 확인으로 승격하지 않습니다. 비밀 값은 브라우저·Git·로그에 넣지 않습니다.

지원 조건 조사와 남은 연결 단계는 [docs/chatgpt-connection.md](docs/chatgpt-connection.md), 엔진 형식·검사·저장은 [docs/engine-v2.md](docs/engine-v2.md)를 참고하세요.

## 저장·복원

- v1 JSON을 읽어 기존 치수·자료 목록·실물 기록을 유지합니다. 형상 데이터가 있는 경우 v2 JSON으로 내보냅니다.
- JSON은 원본 파일을 포함하지 않습니다. ZIP은 원본·형상·근거·제작 설정·최대 10개 이전 형상을 함께 보관하고 SHA-256으로 검증합니다.
- ZIP 복원은 원본에 새 자료 ID를 부여해 기존 IndexedDB 파일을 덮어쓰지 않습니다. 기존 작업이 있으면 먼저 백업합니다.
- 파일당 원본 10 MB, ZIP 합계 60 MB, ZIP 내 메타데이터 8 MB, JSON 직접 가져오기 2 MB, 요소 500개와 윤곽 128점을 지원합니다. 범위를 넘으면 명확히 실패로 표시합니다.
- 브라우저 저장 용량을 초과하면 저장 실패를 알립니다. 장기 보관에는 원본 포함 ZIP을 내려받으세요.

## 코드

| 경로 | 역할 |
| --- | --- |
| `src/design/types.ts` | 이미지 좌표·모형 mm·근거·확인·잠금·실행 기록 |
| `src/design/estimate.ts` | 로컬 이미지 분석·깊이/후면 보완·입면 비교·제한된 보완 |
| `src/design/compile.ts` | 동일 형상에서 모든 화면/파일용 부품 생성 |
| `src/design/geometry.ts` | 윤곽·개구부·수치·관계·중복 검사 |
| `src/design/archive.ts` | v1/v2 읽기·원본 포함 백업·무결성 복원 |
| `src/DesignStudio.tsx` | 자료 선택·PDF·비교·편집·잠금·취소·되돌리기 |
| `server/ai.ts` | AI 연결 상태·과금 차단·구조화 결과 검증 |
| `src/engine.ts` | 기존 수동 생성기와 공통 SVG/DXF/STL 출력 |

번들 의존성 라이선스는 `public/THIRD-PARTY-NOTICES.txt`와 기존 글꼴 라이선스를 따릅니다. 이 파일은 저장소 자체의 라이선스를 지정하지 않습니다.
